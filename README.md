# BRANDON.EXE — Mobile-friendly birthday edition

This is the original cute 3D Brandon birthday game, with mobile layout fixes only. The original dialogue, gifts, characters and ending are unchanged.

## Deploy
Upload `index.html` to the root of your GitHub Pages repository, replacing the previous version. In Settings → Pages choose Deploy from a branch, main, / (root).

## Controls
On phones, use the arrow pad to move, ⤒ to jump, and 💬 to talk. On desktop, use WASD / arrows, Space and E.

The game loads Three.js from a CDN, so an internet connection is required.
